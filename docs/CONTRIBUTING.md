# Contributing | المساهمة

Thank you for your interest in contributing! يرجى اتباع الإرشادات أدناه.

## Branching | الفروع

- main: stable
- feature/*: new work
- fix/*: bug fixes

## PRs | طلبات الدمج

- Use the PR template.
- Keep PRs focused and small when possible.

## Issues | القضايا

- Use the issue templates (bug/feature).

## Large files | ملفات كبيرة

- Prefer GitHub Releases for model artifacts. Consider Git LFS if needed.
