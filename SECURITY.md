# Security Policy | سياسة الأمان

## Reporting a Vulnerability | الإبلاغ عن ثغرة

- English: Please report security issues privately via email or a private issue.
- العربية: الرجاء الإبلاغ عن المشاكل الأمنية بشكل خاص عبر البريد أو قضية خاصة.

Provide:

- Affected files/versions
- Steps to reproduce (if applicable)
- Impact assessment

## Supported Versions | الإصدارات المدعومة

- main branch is supported.

## Response | آلية الاستجابة

We aim to acknowledge reports within 72 hours and provide a remediation plan shortly after.
